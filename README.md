# Atualizações da CENTRAL DE PEDIDOS

Este repositório publica somente os artefatos necessários para atualizar a
CENTRAL DE PEDIDOS. O código-fonte e os componentes administrativos permanecem
em um repositório privado.

## Conteúdo público

- `latest.json`: versão atual, URL do instalador e checksum SHA-256;
- Releases: instalador comercial e respectivo arquivo `.sha256`.

O aplicativo valida o SHA-256 antes de executar qualquer instalador baixado.
